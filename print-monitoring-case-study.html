Professional case study / IT operations

Printer monitoring.
Page-count tracking.

A practical approach to understanding print usage: install a data collection agent (DCA) for network-connected printers, then use Excel to keep track of printed page counts, including for locally connected printers outside the DCA's visibility.

Work typeProfessional IT contribution
DCA coverageNetwork-connected printers only
TrackingPrinted page counts in Microsoft Excel
OutcomeMore organized visibility into page usage; no savings metrics claimed
The challenge

One printing environment.
Different connection types.

A DCA can monitor compatible network-connected printers, but the system I installed did not cover printers connected locally. Tracking page usage across these different connection types required more than relying on the DCA alone.

01

Install monitoring for network printers

I installed a data collection agent (DCA) monitoring system for printers connected to the network. Its coverage did not extend to locally connected printers.

02

Track printed pages in Excel

I used an Excel workbook to track page counts and review print usage, including for printers outside the DCA's monitoring coverage. This was a page-count tracking effort, not a measurement of ink consumed by individual workstations.

03

Connect findings to support workflows

I also have experience purchasing computer peripherals and supplies through vendors and improving supply-ordering procedures. Page-count records provided additional context for understanding printing activity.

Skills demonstrated

Turning support needs
into repeatable information.

01

Practical tool deployment

Installed the monitoring system within its supported network-printer scope and recognized the limits of its coverage.

02

Tracking and analysis

Organized printed page counts in Excel so usage could be reviewed more consistently.

03

Operational awareness

Applied tracking and documentation to a routine IT support and supply-management challenge.

Evidence & limitations

Documented accurately.
Without private data.

This case study describes my work but does not display company page-count data, device details, internal reports, or printer identifiers. I have not published a DCA-to-Excel integration, cost-savings calculation, reduction in ink consumption, or productivity percentage because those outcomes have not been established.
