Professional case study / Operations improvement

Print monitoring.
Better visibility.

Installing a data collection agent (DCA) monitoring system and building a practical Excel tracking workbook to understand which workstations were associated with higher ink usage.

Project typeWorkplace IT contribution
FocusMonitoring, reporting & purchasing workflows
ToolsDCA monitoring system · Microsoft Excel
ResultsMore visibility into high-usage workstations; no quantified savings claimed
Context & problem

From supply requests
to useful information.

Printer ink and supply ordering are recurring parts of desktop support. Making sense of which workstations generate more print demand can provide a stronger basis for investigating usage patterns and planning supplies.

01

Monitoring setup

I installed a DCA monitoring system as part of the print-monitoring effort. This gave the team a tool for observing printing-related activity.

02

Excel tracking

I created an Excel workbook to track workstations associated with higher ink usage, organizing information so patterns could be reviewed instead of relying entirely on ad hoc requests.

03

Procurement context

My vendor purchasing experience included ordering computer peripherals and supplies. Monitoring and tracking were relevant to understanding recurring operational needs.

What this demonstrates

Small improvements.
Operational thinking.

01

02

Data-informed IT operations

Using monitoring tools and spreadsheet analysis to make usage patterns easier to inspect and discuss.

03

Documentation & repeatability

Applying the same process-improvement mindset used in technical documentation, daily service desk checklists, and purchasing workflows.
