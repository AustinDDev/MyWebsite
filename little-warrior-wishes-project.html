Little Warrior Wishes

Nonprofit Website Development & Deployment

Live / In Progress

Real-world nonprofit website · Website development & deployment

Visit live website ↗GitHub source code ↗

Ongoing redevelopment: Facebook and contact-form integrations are being reworked.

Project Overview

I led the end-to-end development and deployment of Little Warrior Wishes, collaborating directly with nonprofit stakeholders to establish a professional online presence. My work covered requirements gathering, planning, design, implementation, testing, and launch, with ongoing improvements to functionality and user experience.

Objective

My goal was to create a publicly accessible website that communicates the nonprofit’s mission and provides ways for visitors to learn more, get involved, and make contact.

My Role & Responsibilities

  • Collaborated with nonprofit stakeholders to gather requirements.
  • Planned and designed the website.
  • Performed hands-on development supported by AI-assisted coding and troubleshooting.
  • Implemented responsive layouts and third-party integrations.
  • Conducted functional, responsive, accessibility, and integration testing.
  • Managed deployment and production verification.
  • Continued maintenance and redevelopment after launch.

Technologies & Tools

  • Next.js
  • React
  • TypeScript
  • Tailwind CSS
  • Vercel
  • Formspree
  • Facebook Page Plugin integration

Formspree and the Facebook Page Plugin are part of the integration work currently being revised.

Implementation Approach

I gathered stakeholder requirements, planned the site’s structure and presentation, and developed the website iteratively. I used AI-assisted coding and troubleshooting as support for hands-on implementation, then tested changes and reviewed the deployed site.

I investigated options for connecting external content and contact functionality, implemented the integrations, and used testing to identify areas requiring further improvement.

Challenges & Solutions

The main integration challenge was bringing Facebook content and contact-form functionality into the website while maintaining a responsive and reliable user experience.

I investigated integration options, implemented functionality, and tested the results. The Facebook and contact-form integrations are currently being reworked; I do not consider that work complete.

Testing & Validation

During development, I conducted functional, responsive, accessibility, and integration testing, followed by deployment and production verification. That testing helped identify areas for continued improvement.

These activities describe my project work, rather than a claim of formal accessibility certification or complete integration reliability. The Facebook and contact-form changes still need further testing as redevelopment continues.

Outcomes & Current Status

I delivered a publicly accessible website that established a professional online presence for Little Warrior Wishes. The site remains live while maintenance, improvements, and redevelopment continue.

The current status is Live / In Progress. Facebook and contact-form integrations remain under revision.
