Overview

DaltonDev.me is my personal professional portfolio and an ongoing development project. I designed, developed, and deployed it to present my experience in IT operations, project delivery, cybersecurity education, and technical engineering.

Project Objective

I wanted a central professional platform for my career experience, technical capabilities, projects, and accomplishments, while giving myself an environment for continuous learning and web development.

My Role

Project Owner & Developer

  • Directed the design and technical implementation.
  • Developed portions of the application hands-on.
  • Used ChatGPT and Codex to assist with implementation, troubleshooting, and improvements.
  • Established consistent navigation and visual design.
  • Organized content into Projects, Case Studies, and professional experience.
  • Tested functionality, responsive behavior, accessibility, and performance as part of iterative development.
  • Managed deployment and ongoing development.

Technologies

  • HTML
  • CSS
  • JavaScript
  • Git
  • GitHub
  • ChatGPT
  • Codex

The current repository uses static HTML, CSS, and JavaScript. Pages share stylesheets and navigation behavior without a framework build step.

Architecture & Design

I separated technical Projects from professional Case Studies so visitors can explore deliverables and the decisions behind them. About and Professional Experience provide the career context, with shared navigation connecting the sections.

The content uses three categories: Project Management & Delivery, IT Operations & Leadership, and Technical Engineering & Solutions. Shared layout patterns, cards, typography, stylesheets, and JavaScript keep the presentation consistent across static pages.

Development Approach

I work iteratively: refine the information architecture, implement a focused change, validate links and behavior, and review the result. ChatGPT and Codex support implementation and troubleshooting alongside my hands-on development.

Featured work is distinguished from standard project entries. Little Warrior Wishes remains featured; this portfolio is a standard project. Additional work can follow the existing card and detail-page conventions without adding complex filters.

Challenges

The main challenge was organizing a broad professional background into a cohesive portfolio that communicates technical experience, project delivery capabilities, and long-term IT leadership goals.

I addressed that through distinct Projects and Case Studies sections, consistent categories, and clear separation between actual roles, project scope, and career aspirations.

Testing & Validation

My development process includes checking functionality, navigation, local routes and anchors, responsive behavior, accessibility, and performance considerations. I use those checks to guide improvements rather than claim unverified scores or certification.

For this project entry, automated checks cover HTML structure, local references, preservation of existing content, and JavaScript syntax. Browser-based visual, mobile, and performance verification still requires a manual review.

Outcomes

I launched a publicly accessible professional portfolio that continues to evolve through new content, technical enhancements, and design improvements. It provides a central place to explore my background and work.

Continuous Improvements

The platform is live and continuously improving. I continue refining content, navigation, responsive layouts, accessibility, and the presentation of reviewed projects and professional accomplishments.

Updates in the development branch are reviewed separately from the currently published site.
